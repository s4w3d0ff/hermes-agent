# STE vs Non-STE — real example pairs

All pairs are genuine: sentence examples come verbatim from the ASD-STE100 Issue 9 dictionary entries (the `nonste_example` / `ste_example` fields) or from Part 1 of the standard. Format: rejected word -> approved alternative(s).

## Word swaps with same part of speech (word-for-word replacement, Rule 9.1 OK)
| Non-STE | STE | Note |
|---|---|---|
| abandon the test procedure | STOP the test procedure | IF THE VALUES ARE INCORRECT, STOP THE TEST PROCEDURE. |
| apply too much force to the control wheel (vigorously) | DO NOT APPLY TOO MUCH FORCE | WHEN YOU MOVE THE CONTROL WHEEL, DO NOT APPLY TOO MUCH FORCE. |
| Do an evaluation of the test results | MAKE AN ANALYSIS OF THE TEST RESULTS | evaluation (n) rejected -> ANALYSIS |
| Make certain that the identification plates are legible | MAKE SURE THAT YOU CAN READ THE IDENTIFICATION PLATES | legible (adj) rejected |
| Certify the change in the logbook | WRITE THE CHANGE IN THE LOGBOOK | certify (v) rejected |
| The boarding bridge collapsed. | THE BOARDING BRIDGE FELL. | collapse -> FALL |
| If the gears do not mesh correctly, add a shim. | IF THE GEARS DO NOT ENGAGE CORRECTLY, ADD A SHIM. | mesh (v) rejected -> ENGAGE |
| Do the weighing procedure in the following order: | DO THE WEIGHING PROCEDURE IN THIS SEQUENCE: | order (n sense "sequence") -> SEQUENCE |
| If you have the option, do the inspection in daylight. | IF IT IS POSSIBLE, DO THE INSPECTION IN DAYLIGHT. | option rejected -> POSSIBLE construction |
| Slowly reduce the speed. | SLOWLY DECREASE THE SPEED. | reduce (v) rejected -> DECREASE |
| Let the sediment settle at the bottom of the container. | LET THE SEDIMENT COLLECT AT THE BOTTOM OF THE CONTAINER. | settle rejected |
| These maintenance activities can be done by a subcontractor. | A SUBCONTRACTOR CAN DO THESE MAINTENANCE TASKS. | activity -> TASK (plus active voice) |

## Phrasal units / verb phrases (Rule 9.3 — do not make phrasal verbs)
| Non-STE unit | Approved alternative | STE example |
|---|---|---|
| Turn off the computer. | STOP THE COMPUTER | turn off rejected as a unit |
| Carry out the task | DO / PERFORM (see dictionary alternatives) | — |
| Look up the value | FIND | look up rejected |
| Account for the difference | EXPLAIN / INCLUDE | account for rejected |
| By means of a wrench | WITH A WRENCH | by means of rejected -> use preposition |
| Close to the fuselage (meaning "near") | NEAR / CLOSE TO only when approved sense | DO NOT USE SOLVENTS NEAR FLAMES OR SPARKS. ("close" adj = near is not the approved meaning) |

## Part-of-speech changes — rebuild the sentence (Rules 1.2, 9.1)
| Non-STE | STE | Why |
|---|---|---|
| Make sure that the valve is operable. | Make sure that the valve can operate. | operable adj rejected; alternative "operate" is a verb -> new construction |
| Test the system for leaks. | Do a test for leaks in the system. / Do the leak test of the system. | "test" approved noun only, not verb |
| Dim the lights. | Set the lights to the dim position. | "dim" adjective only |
| Check the laptop battery. | Do a check of the laptop battery. | bare "check"+object pattern |
| Confirm that ... (in place of MAKE SURE) | Make sure that ... | ensure/confirm rejected -> MAKE SURE |
| A value of 2 mm is acceptable. | A value of 2 mm is permitted. | acceptable adj rejected -> PERMITTED |

## Sentence structure fixes (Sections 3, 4, 5) — verbatim from Part 1
| Non-STE | STE | Rule |
|---|---|---|
| The operator has adjusted the linkage. | The operator adjusted the linkage. | 3.2 no present perfect |
| The seat is to be installed before you install the cushion | Before you install the cushion, install the seat. | 3.4/3.6 remove "to be" + active voice |
| The volume control can be adjusted. | You can adjust the volume control. | 3.4 passive -> active |
| The temperature must be adjusted. | Adjust the temperature. | imperative instead of must-passive |
| The sleeve will be adjusted by the robot. | The robot will adjust the sleeve. | agent first, active voice |
| Follow the safety instructions. | Obey the safety instructions. | 1.3 approved meaning (follow = come/go after only) |
| Runway light connection resistance calibration (5-word noun) | Calibration of the resistance of the runway light connection. | 2.1 max three words per multi-word noun |
| Install the forward turbine overheat thermocouple terminal tags. | Install the terminal tags on the forward overheat thermocouple of the turbine. | 2.1 |
| Remove the engine transmission housing attachment bolts. | Remove the bolts that attach the transmission housing to the engine. | 2.1 |
| The ohmmeter gives an indication of 450 ohms. | The ohmmeter shows 450 ohms. | 3.7 direct verb over noun |
| Before the removal of the unit, make sure that the power supply is OFF. | Before you remove the unit, make sure that the power supply is OFF. | 3.7 |
| When you are doing this procedure, obey all the safety precautions. | Obey all the safety precautions while you do this procedure. (simple tenses) | 3.5 -ing form restriction |

## Safety pattern (Section 7)
```
CAUTION: DO NOT TOUCH THE FAN BLADE. YOU CAN BE BURNED BY THE HOT SURFACE.
WARNING: WEAR SAFETY GLASSES WHEN YOU GRIND METAL.
CAUTION: THE ENGINE CAN START SUDDENLY, USE A CHOCK ON EACH WHEEL.
```
Structure = risk word + command/condition + result explanation. WARNING = injury/death; CAUTION = damage to objects.

## Punctuation / count examples (Section 8)
- Non-STE: `The bolt is installed; it must be torqued.` -> STE: `Install the bolt. Then, torque the bolt to 25 Nm.` (no semicolons)
- Word-count treatment (each counts as ONE word): `(9)` item reference = 1; `2 mm` = 1; `400 ohms` = 1; a hyphenated unit like `pop-out` = 1; quoted text or a proper noun = 1.
